# 꼬마 슈퍼마켓

만 3~7세 아이가 슈퍼마켓 놀이로 듣기·수 세기·말하기를 해 보는 체험 앱입니다.

## 놀이 두 가지
- **내가 점원이에요**: 동물 손님이 "우유 한 개랑 사과 두 개 주세요"라고 말하면 아이가 진열대에서 물건을 눌러 장바구니에 담아 건넵니다. 틀리면 손님이 무엇을 고치면 되는지 알려 줍니다.
- **내가 손님이에요**: 점원이 물건 그림을 보여 주면 아이가 마이크 버튼을 누르고 말로 주문합니다. 빠뜨린 물건, 개수, 그림에 없는 물건을 알려 주고, 틀린 개수는 답을 말하지 않고 다시 세어 보게 합니다. "따라 말하기 듣기"로 본보기 문장을 들을 수 있습니다.

## 나이별
| 나이 | 점원 놀이 | 손님 놀이 |
|---|---|---|
| 3~4세 | 먹거리 통로만, 한 가지, 1~3개, 개수 점 | 한 가지, 1~2개, 1개면 개수를 안 말해도 정답 |
| 5~6세 | 두 통로, 한두 가지, 1~4개, 점과 숫자 | 한두 가지, 1~3개, "주세요" 붙이기 안내 |
| 7세 | 두 통로, 두 가지, 1~5개, 숫자 | 두 가지, 1~5개 |

## 개인정보와 비용
- 카메라는 쓰지 않고, 아무것도 저장하지 않습니다. 이 앱에는 서버가 없습니다.
- 손님 놀이에서 마이크를 켜면, 브라우저(Chrome·Edge)가 말소리를 글자로 바꾸려고 회사 서버(Google·Microsoft)로 보냅니다. 처음 마이크를 누를 때 선생님 확인 안내가 나오고, 첫 화면의 선생님 설정에서 끌 수 있습니다.
- 마이크가 없거나 못 알아들을 때는 선생님이 듣고 "선생님: 잘 말했어요"를 눌러 진행합니다.
- 비용 없음: 목소리는 브라우저 내장 음성, 글꼴은 Google Fonts(Jua, Noto Sans KR)이고 AI API를 쓰지 않습니다.

## 실행
```
npm install
npm run dev     # http://localhost:5173 (마이크는 localhost 나 https 에서만 됩니다)
npm test
npm run build   # dist/ 를 정적 호스팅(Vercel 등)에 올리면 됩니다
```
