# 꼬마 과일가게

유아가 가게 점원이 되어 보는 체험 놀이입니다. 동물 손님이 "사과 두 개 주세요"라고 말하면 아이가 과일 카드를 눌러 쟁반에 담고 건넵니다. 틀리면 손님이 무엇을 고치면 되는지 알려 줍니다.

- 대상: 만 3~5세. 선생님이 옆에서 함께 하는 활동으로, 손님 5명이면 한 판(3~5분)이 끝납니다.
- 단계: 쉬움(한 가지, 1~3개) · 보통(한 가지, 1~5개) · 어려움(두 가지, 1~3개씩)
- 개인정보: 마이크와 카메라를 쓰지 않고, 아무것도 저장하거나 서버로 보내지 않습니다.
- 비용: 없음. 손님 목소리는 브라우저 내장 음성(`speechSynthesis`)으로 읽고, AI API·서버를 쓰지 않습니다.
- 그림: 기기에 깔린 이모지 글꼴을 씁니다. 기기마다 모양이 다를 수 있습니다.

## 실행

```
npm install
npm run dev     # http://localhost:5173
npm test
npm run build   # dist/ 를 정적 호스팅(Vercel 등)에 올리면 됩니다
```
