꼬마 역할놀이 마을 설계도

만 3~5세 아이가 가게 놀이로 듣기·수 세기·말하기를 하는 웹 앱입니다. 서버 없이 브라우저 하나에서 모두 돌아갑니다. 아래 그림은 바깥에서 안쪽 순서로, 기기와 바깥 서비스 → 화면 흐름 → 놀이 갈래 → 한 판의 데이터 → 코드 모듈로 좁혀 들어갑니다.

React 19TypeScript 5.9Vite 8Vitest 5 + Testing LibraryWeb Speech APIlocalStorageVercel 정적 배포

1. 앱이 실제로 사는 곳

내려받은 뒤에는 모든 일이 기기 안에서 일어납니다. 기기 밖으로 나가는 데이터는 손님 놀이에서 마이크를 켰을 때의 소리 하나뿐입니다.

2. 화면이 바뀌는 길

App.tsx 의 screen 상태 하나가 다섯 화면 중 무엇을 그릴지 정합니다. 라우터는 없습니다.

3. 가게 종류 × 역할 = 놀이 화면

가게마다 kind(일반 가게·병원·키오스크)가 있고, 아이는 점원이나 손님 역할을 고릅니다. 둘을 곱한 여섯 칸이 각각 다른 컴포넌트입니다. 말하기 놀이 셋은 TalkPlay 하나를 같이 씁니다.

가게 종류 (kind)점원 · 듣고 고르기손님 · 말하기규칙 파일
shop
슈퍼마켓·과일가게·빵집·문구점·분식집·꽃집·아이스크림·옷가게 (8곳)		 ClerkPlay

kiosk

나이 단계는 '1'(처음 해요)·'3'·'5'·'7' 네 칸입니다. 한 손님에게 두 번 넘게 막히면 easier() 로 다음 손님을 한 단계 낮추고, 한 번에 맞히면 harder() 로 아이가 고른 단계까지 되돌립니다.

4. 손님 한 명이 지나가는 동안의 데이터

두 놀이는 주문을 만드는 곳과 판정 결과(Verdict)를 쓰는 곳이 같고, 가운데 입력만 다릅니다. 점원 놀이는 손가락, 손님 놀이는 목소리입니다.

5. 코드 모듈이 서로 부르는 관계

화살표는 import 방향입니다. 맨 아래 game.ts 와 sound.ts 는 React 를 모르는 순수 함수라서 화면 없이 테스트됩니다.

빌드와 테스트

npm run build 는 tsc --noEmit 으로 타입을 먼저 검사하고 Vite 로 dist/ 를 만듭니다. npm test 는 Vitest 가 jsdom 환경에서 테스트 파일 11개를 돌립니다(이 페이지를 만들며 실행하지는 않았습니다).

설정 파일

vite.config.ts 하나에 React 플러그인과 테스트 설정(setupTests.ts)이 같이 있습니다. 런타임 의존성은 react·react-dom 둘뿐입니다.
